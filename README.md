# ACME HR Salary Management System

## Project Overview
This project is a web-based salary management application designed for HR Managers at ACME organization. It allows them to manage employee data, update salaries, track compensation history, and view organizational analytics for up to 10,000 employees.

## Assessment Goal
Built as part of the Engineering Assessment for the Software Craftsperson / Node.js / TypeScript II role. The solution demonstrates clear product thinking, structured architecture, high code quality, and the effective use of AI tools in software engineering.

## Planned Architecture
The system is built as a **Modular Monolith** to balance rapid development with maintainability.
- **Frontend:** React, TypeScript, Redux Toolkit, RTK Query.
- **Backend:** Node.js, Express, TypeScript, Zod.
- **Database:** MySQL, Prisma ORM.
